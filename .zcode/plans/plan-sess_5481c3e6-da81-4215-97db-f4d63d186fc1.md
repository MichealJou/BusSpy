## 目标
让用户打开 BusSpy 的 dmg 时,能直接看到一个"首次运行请双击.command"脚本图标,双击就能去掉"无法验证开发者"提示,不用翻仓库、不用打命令。

## 方案:CI 打包后重制 dmg,塞入信任脚本

### 背景结论(已查证)
- Tauri 2 官方不支持往 dmg 根目录加文件(`bundle.macOS.files` 是塞进 .app 内部,用户看不到)。
- `tauri-action` 省略 `tagName`/`releaseName`/`releaseId` 可只构建不上传,并输出 `artifactPaths`。
- macOS 原生 `hdiutil` 可重制 dmg,CI 无需装额外工具。

### 新增/修改文件

#### 1. 新增 `scripts/dmg-trust.command`(放进 dmg 的信任脚本)
- `.command` 后缀:macOS 双击自动在终端执行(不是 .sh,那会用文本编辑器打开)
- 逻辑:处理同目录的 `BusSpy.app`(dmg 挂载点)和 `/Applications/BusSpy.app`(用户已拖过去的),都去掉 quarantine
- 中文提示文字,告诉用户处理完成、可以打开应用、升级后重新执行一次
- 内容大致:
```bash
#!/bin/bash
set -e
echo "BusSpy 首次运行授权工具"
echo "正在去掉 macOS 的未验证开发者提示..."
for APP in "$(dirname "$0")/BusSpy.app" "/Applications/BusSpy.app"; do
  if [ -d "$APP" ]; then
    xattr -dr com.apple.quarantine "$APP" 2>/dev/null || true
    xattr -cr "$APP" 2>/dev/null || true
    echo "已处理:$APP"
  fi
done
echo "完成!现在可以正常打开 BusSpy 了。"
echo "提示:以后每次升级 BusSpy,如果再次提示无法打开,重新双击本脚本即可。"
```

#### 2. 新增 `.github/scripts/rebuild-dmg.sh`(CI 里重制 dmg)
- 入参:原 dmg 路径
- 流程:挂载原 dmg → 提取 .app 到临时目录 → 创建 Applications 快捷方式 → 复制"首次运行请双击.command"(从仓库 scripts/ 读)并赋可执行权限 → 卸载原 dmg → 用 hdiutil create 生成新 dmg 覆盖原 dmg
- 严格 UTF-8(LANG=en_US.UTF-8),处理中文文件名

#### 3. 改 `.github/workflows/release.yml`
- **macOS 两个 job(Apple Silicon + Intel)拆成三步**:
  1. 构建(不上传):`tauri-action` 省略 `tagName`/`releaseName`/`releaseId`,`id: tauri-build`
  2. 重制 dmg:调 `rebuild-dmg.sh`,从 `artifactPaths` 里找 `.dmg`,重制覆盖
  3. 手动上传:用 `gh release upload` 把所有产物上传到 release
- **Windows / Linux 两个 job 不动**:保持 `tauri-action` 一步构建+上传(它们没有这个问题)

### 实现注意点
- macOS runner 原生支持 UTF-8,中文文件名"首次运行请双击.command"在 CI 里安全。
- `hdiutil create` 用 `-format UDZO`(压缩),产物可正常分发。
- 重制后的 dmg 图标布局是默认的(无美观排列、无背景图),用户打开能看到三个文件:BusSpy.app、Applications、首次运行请双击.command。美观布局需要大量 AppleScript 维护成本高,暂不做。
- Windows/Linux job 完全不受影响。

### 不改动
- `scripts/macos-trust.sh`(仓库脚本,给开发者用)保留,不删。
- README 的说明保留/微调。
- Rust 后端、前端代码完全不动。

### 验证
1. `bash -n` 语法检查两个 shell 脚本
2. 工作流 YAML 人工审阅(无法在本地跑 CI)
3. 推一个测试 tag 触发 CI,验证:Release 里 macOS 的 dmg 打开后能看到"首次运行请双击.command",双击能在终端执行并去掉 quarantine
